# KAIROS iPhone V2

## Codes
- ABEG: `1029`
- EXCLU: `TIME`

## Ajouter les audios
Place les fichiers ici:
- `assets/audio/abeg.mp3`
- `assets/audio/exclu.mp3`

Puis remplace le placeholder `alert(...)` dans `app.js` par un vrai lecteur `<audio>` ou demande à ChatGPT de le brancher.

## Déploiement GitHub -> Vercel
1. Connecter le repository `kairos-experience` au projet Vercel.
2. Sur GitHub, `Add file` -> `Upload files`.
3. Uploader **le contenu de ce dossier**, pas le ZIP.
4. Commit sur `main`.
5. Vercel redéploie automatiquement.
